## Run notes

- A first pilot (batch 2026-10-28-e3-pilot-01, N=100, same seed) was stopped after about 5 hours with no results on disk: Stryker writes its report only when the whole run ends, the mutate ranges made it test 213 live mutants rather than 100 (other mutators on each sampled node), and the machine's load average stayed between 200 and 475 from other agents' test runs. Its sample is kept in eval/results/E3/2026-10-28-e3-pilot-01/; it has no outcomes and no run records.
- This pilot (2026-10-28-e3-pilot-02) is the first 16 mutants of the same seeded shuffle, which is itself a simple random sample of 16. Stryker now runs the checks only for the sampled mutant ids (eval/e3/stryker-gate.sh) and logs every real run, and Stryker and the POCP replay ran at the same time (PARALLEL=1) so both saw the same load.
- 16 mutants is a pilot: the intervals below are wide, and nothing here supports a claim beyond 'the two runners were compared on these mutants'.

## Reproduce

```bash
# Stryker lives outside the repo; POCP stays zero-dependency.
STRYKER_DIR=$(mktemp -d) && (cd "$STRYKER_DIR" && npm init -y >/dev/null && npm i @stryker-mutator/core@9.6.1)
git checkout 80109b0408f05d251f86df4b4b6eb1d54d4075bd
STRYKER_DIR="$STRYKER_DIR" N=16 SEED=20261028 JOBS=4 BATCH=2026-10-28-e3-pilot-02-repro eval/e3/run.sh
```

`eval/e3/run.sh` prints each step's exact command. To only regenerate this file from the committed records and raw files:

```bash
node eval/e3/report.js --raw eval/results/E3/2026-10-28-e3-pilot-02 --batch 2026-10-28-e3-pilot-02
```
